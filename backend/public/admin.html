添加节点路由

先在“节点管理”为每个节点设置一次 llama-server API Key；该节点的全部模型路由都会使用这把密钥。

API 密钥

个人模式创建服务器统一 Key；服务商模式查看用户申请的 Key。完整密钥只在创建时显示一次。

服务商模式的 API Key 必须关联用户账户以便计费。用户请从自己的控制台申请；管理员可在此查看并吊销。
选择后，此 Key 只能调用指定的公开模型。

用量统计

按请求追踪模型、Token 数、计费金额和访问来源；可按服务商账号核查调用明细。

用户与订单

管理服务商模式的用户账户余额、状态与充值订单。

系统设置

配置访问模式、服务商邮箱、支付宝与公网回调地址。

服务商模式要求 HTTPS 公网地址、SMTP 邮箱配置和支付宝应用 ID、商户 ID、应用私钥及支付宝公钥全部填写并保存。密钥只在服务器加密保存，不会回传到浏览器。
服务商模式必填 HTTPS 地址，用于支付宝异步通知和支付返回。

密钥已创建

请立即复制并保存在安全的位置。关闭后无法再次查看完整密钥。

节点 API Key

为 配置 llama-server HTTP 访问密钥。服务器加密保存，并用于此节点的全部路由。
更换后，下一次调度即开始使用新密钥。留空不能查看已保存密钥。

调整 API Key 限额

选择后，此 Key 只能调用指定的公开模型。
